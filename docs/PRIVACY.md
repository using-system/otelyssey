# Privacy policy

otelyssey is a catalog: a list of agent plugins, published as files in this
repository. It collects no personal data, sets no cookies and runs no
service of its own.

Adding the marketplace to a host (Claude Code, Codex, Copilot CLI, VS Code,
Grok Build and the others) is handled by that host and by GitHub, under their
own policies. Each plugin listed here is published by its own author, from
its own repository, under its own privacy policy; read it before installing.

A submission is a GitHub issue: what you write there is public, under
GitHub's privacy statement. The repository's automated pipeline reads it and
rules on it, on GitHub Actions, including an AI reviewer run through GitHub
Copilot, under GitHub's terms.
